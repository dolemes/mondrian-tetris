# Mondrian Tetris

Puzzle de blocos estilo Tetris com estética neoplástica de Piet Mondrian. Arquivo único (`index.html`), HTML5 Canvas + JavaScript vanilla.

**Jogue online:** https://www.dolemes.com/games/mondrian-tetris/

Ou abra `index.html` localmente no navegador. Controles: setas/WASD, Espaço (queda instantânea), P (pausa); botões virtuais em telas de toque.

Três fases: Grande Plano Vermelho (1921), Vermelho, Azul e Amarelo (1930), Broadway Boogie Woogie (1942–43).
